## Standards

### Liquid & HTML
- Max 3 levels of Liquid nesting; extract to snippets.
- `| asset_url` for every file in `/assets`; never hardcode static URLs.
- Use `{% render %}`, never `{% include %}`.
- Every new section/block has a unique id: `id="{{PREFIX}}-{{ section.id }}"`.
- No inline colors — only the theme's color tokens (`var(--color-*)` or equivalent; verify names).
- Semantic HTML: heading order h1→h6, landmarks (`main nav aside footer`).
- Do not inject elements between fixed-height containers in drawers; inject inside the scrollable content area. *(Re-verify against this theme version — see architecture.md constraints.)*

### CSS
- New variables: `--{{PREFIX}}-*`. New classes: BEM `.{{PREFIX}}-[block]__[element]--[modifier]`.
- Never modify the theme's base color tokens; override with specificity. Prefer `@container` over `@media` for components.
- Mobile-first breakpoints: 768 / 1024 / 1440.

### JavaScript
- Progressive enhancement; event delegation; batch DOM reads/writes; `requestAnimationFrame` for visuals; respect `prefers-reduced-motion`; manage focus.
- Add-to-cart: use the theme's own product-form component/contract *(find it in source; bare `<form>` may skip the theme's AJAX/cart events)*.

### Schema
- Range settings ≤ 101 steps and `max` ≤ 9999. `visible_if` can fail on `collection` pickers in some CLI versions.
- Descriptive labels, `info` for non-obvious settings, sensible defaults, grouped settings.

### Performance · a11y · SEO · Security
- Lazy-load below-fold images, `srcset` + aspect ratio, WebP, < 200 KB images; JS < 100 KB gz.
- WCAG 2.1 AA: keyboard, visible focus, 4.5:1 contrast, labels, alt text, 44×44 px targets.
- One H1, unique titles < 60 chars, meta descriptions < 160, JSON-LD for products.
- Escape user input (`| escape`), no `| raw` on user content, external scripts only from trusted CDNs over HTTPS.
